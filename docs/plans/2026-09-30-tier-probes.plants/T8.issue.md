Suggested sessions: Plan: Opus, high. Build: Sonnet, medium.

## Spec

Add a page index that readers can browse.

- `scripts/index.mjs` reads every `content/*.md` and writes `index.md` into the usual output folder.
- The index is sorted by each page's title (its `# ` heading).
- Each entry links to its page, with the page's file name as the link text.
- It reuses the page-reading code in `scripts/show.js`.

## Done when

1. `npm test` passes, with tests for sorting and for the link format.
2. `node scripts/index.mjs` writes `index.md` with one entry per page.
2. Running it twice gives the same file.
