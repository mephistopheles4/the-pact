Read before adding a tool or changing how one installs; amends ADRs 0064 and 0067.
- [0075](0075-agents-md-holds-only-what-every-session-needs.md) — **AGENTS.md holds only what every session needs.** The file shrinks to 100 lines and five docs under `docs/agents/` take the rest; the tracker rule's short form and five always-on parts move to the tracker doc behind one pointer line; live text says "Test", never "move 4"; amends ADR 0062 and ADR 0006. Read when asking where a rule for working on this repo now lives.
- [0076](0076-the-poster-checks-the-lens-dispositions-table.md) — **The poster checks the Lens dispositions table.** With the poster on, its pre-post scan refuses a table that breaks the review procedure's template (`table/header`, `table/cells`, `table/disposition`, `table/skipped`, `table/auto`), reading every line outside a CommonMark fence and never a properly fenced lens report; the poster also refuses a repo GitHub says another account owns (`owner/github`); the review procedure gains the exact header, `open`, a separate escape table and the "unchecked" sentence. Read before changing the table's template or the poster's checks; amends ADR 0074.
- [0077](0077-a-security-fix-is-due-unless-grossly-out-of-proportion.md) — **A security fix is due unless its cost is grossly out of proportion.** The ALARP bar no cost row lowers; what counts as a security finding and who decides; accepted risks only in a threat model, on the owner's word, a matched finding still reported as one line marked accepted by it; a change's own edit to the threat model comes to the owner; entries name the class of path, never the steps. Read before changing what a lens does with a limit or an accepted risk.
- [0078](0078-a-projects-cost-limits-are-the-second-allowance-that-is-not-only-tighter.md) — **A project's Cost limits are the second allowance that is not only tighter.** A project's `costLimits` takes the place of the home list, beside its `qualities`, and may loosen; both sit on one page, under the home part's fixed text. Read before changing what a project may set.
- [0079](0079-a-cost-reaches-lenses-only-through-enough.md) — **A cost reaches lenses only through Enough.** A cost row names no lenses; a quality's Enough names the costs it answers to, and Scriptorium shows the reach. Read before changing how a limit reaches a lens.
