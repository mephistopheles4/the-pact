**2026-11-26.** The owner's pick, relayed by the lead session (PACT-105, spec 0007 S2 item 57).

## What changed

- **Models.** The rules line names Gemini 4 Neon for planning and Gemini 4 Hydrogen for building, each a slug holding `<effort>`, and says to take the effort from the tier table.
- **Agents.** A harness description may name a model per agent (`agentModels`). Antigravity's puts every lens and `scout` on `flash` and the security pair on `pro`. Claude Code and Codex render as before.
- A person's own `models` for Antigravity set its rules line alone. Their own `agentModels`, or a model an agent's file or setting names outright, changes an agent's.
- **Scriptorium.** The page in the pact folder starts at the folder's agent settings, a save keeps each one not changed on it, the add form takes `defaultInstall`, and Antigravity's row says its agents carry no effort.
