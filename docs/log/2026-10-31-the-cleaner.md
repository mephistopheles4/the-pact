# The cleaner

#438, thorough tier on the sensitive route, planned and specified by plan-438, built by build-438, led by the headchef. The proceed on revision 3 was the lead's own pick under the owner's level-3 command (decision 325), not the owner's words.

A gate that reads shell text to tell worktree removals apart could not be made complete (grimoire PR 470), so the cleaner runs its own fixed git commands: a name-back with a tag per worktree, one yes, then removals bound to the tags (ADR 0124). Probes on git 2.55 showed what git refuses and what it doesn't; the tool's own work is the rows it doesn't. The spec pair and the security pair read two Design rounds; round 2 was declared final.

The build wrote `claude/tools/cleaner.mjs` test-first, its twelve claims on real git in throwaway repositories (`gate/tests/cleaner.test.mjs`), then the install's deny rules and their record key, the rules file part and the builder's tool list. It keeps a worktree whose branch name is outside the allowed set, where the spec held two readings. The cloud copy installs no tool.
