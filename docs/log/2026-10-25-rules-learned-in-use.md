# Rules learned in use ship in the pact

#399 and #400 in one change, standard tier, planned and built on Opus at medium by pact-399-400, led by head-chef-field-test. The lead answered the plan's questions under the owner's auto-mode instruction. The owner's own answers came by relay through the lead: the installer warning goes to its own issue, and the lead-relay clause goes in.

Twenty rules that a lead session had kept in its machine-local memory move into the pact: two posting rules, two lens-running rules and a security-fix loop stop in `claude/review.md`; the asking rule, dictated words, Auto-fix, CodeRabbit's pass signal, the skill check and Fable in `claude/CLAUDE.md`; and nine tool traps in a new last section of the rules file (ADR 0115). Each new rule sits in plain prose outside the configurable blocks, so `builder/default-config/` and the builder page are unchanged; the cloud copy is regenerated.

The spec pair's first round on spec revision 1 was blocking. The installer warning, the twenty-first rule, needed a git command the bootstrap's gate test forbids, and its warning would print a session-writable commit uncleaned; both lenses marked those findings security?. On the owner's word it moved to #407, with its three open findings, and this change keeps only the install guide's fast-forward line. The other findings were fixed in revision 2: reasons restored, wording that fits anyone who installs the pact, exact anchors, and a Needs a human section.

No gate test was added: since ADR 0069 the gate holds no rule text word for word, so the rules hold by review and by use.
