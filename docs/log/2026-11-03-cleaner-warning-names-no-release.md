# The cleaner's warning names no release

Quick tier, on Opus. The owner asked for this in a session, after an install's dry run showed the warning; there is no issue.

The installer's warning for the cleaner told the reader to turn it on only after a named Brigade release. That sentence goes from the warning and its test, from `docs/install.md`, from `docs/cleaner.md` and from the cleaner's line on the Scriptorium page. The warning keeps what the tool does and that its deny rules are a speed bump, not a gate. The installer never checked that advice against anything installed.

The deny rules themselves are unchanged. `claude/tools/cleaner.mjs` and ADR 0124 still name Brigade.
