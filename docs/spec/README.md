# Specs

This folder holds the repo's specs, one file each: `<NNNN>-<slug>.md`, with `NNNN` four digits from `0001`. Whether a spec counts is decided by the owner's rule, `~/.claude/tracker.md` ("Specs in the tree"), not by this file. Every file here is public, so a spec holds no secret, personal detail, open security reason or Linear id beyond a team key.

To add a spec: write the file, put its line at the top of "All specs" (and delete `None yet.` there if it is the first), and change nothing else.
